1. CHARACTERS & LPC-STYLE MONSTERS  (composed sprite sheets)
==============================================================================

These sheets were assembled from the Universal LPC Spritesheet Character
Generator asset library. Each is a 13 x 21 grid of 64x64 frames:

    rows  0- 3  spellcast  (7 frames)   up / left / down / right
    rows  4- 7  thrust     (8 frames)   up / left / down / right
    rows  8-11  walk       (9 frames)   up / left / down / right   (frame 0 = idle)
    rows 12-15  slash      (6 frames)   up / left / down / right
    rows 16-19  shoot      (13 frames)  up / left / down / right
    row  20     hurt/die   (6 frames)

A matching <name>.json sits next to every sheet with the frame ranges already
worked out for Phaser's this.anims.create().

<name>_extended.png is the raw 13 x 46 generator output (adds watering, idle,
jump, run, sit, emote, climb). Those extra rows exist on the body layers but
NOT on most armour/clothing layers, so characters appear partly undressed
there. Use the 21-row sheet unless you specifically need those animations.

Generator / asset library:
  https://github.com/sanderfrenken/Universal-LPC-Spritesheet-Character-Generator
  Original project: Liberated Pixel Cup (https://lpc.opengameart.org/)
  Licenses: CC-BY-SA 3.0 and GPL 3.0 (dual). Some layers add OGA-BY 3.0.
  ATTRIBUTION REQUIRED — yes, for every file listed below.

4. HOUSEKEEPING
==============================================================================

Dungeon Crawl Stone Soup tiles: DCSS states that the majority of its tiles are
released under CC0, with a documented list of tiles whose ownership could not
be confirmed. Every file copied here was filtered against that exclusion list
(https://github.com/crawl/tiles -> TILES_UNDER_UNKNOWN_LICENSE.md) before being
included, so nothing on that list is in this bundle.

Kenney assets came from the ETdoFresh/kenney.nl GitHub mirror of kenney.nl.
Each pack keeps its original License.txt. All Kenney assets are CC0 1.0.

KayKit assets came from Kay Lousberg's own GitHub organisation
(github.com/KayKit-Game-Assets). Each pack keeps its original LICENSE.txt.
All KayKit packs here are CC0 1.0.

NOT INCLUDED (blocked from this sandbox's network, download manually if wanted):
  * Quaternius CC0 low-poly packs      https://quaternius.com/
  * Poly.pizza CC0 model library       https://poly.pizza/
  * itch.io free asset packs           https://itch.io/game-assets/free
  * Direct kenney.nl / opengameart.org downloads (the mirrors above were used
    instead — same files, same licenses)
  There is no CC0 low-poly DRAGON in this bundle; Quaternius' "Fantasy
  Monsters"/"Dragons" packs (CC0) are the obvious fill-in. The 2D dragons in
  assets/monsters/tier4_dragon/dcss_dragons are CC0 and ready to use.
